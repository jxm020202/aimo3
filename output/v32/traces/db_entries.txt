Question: In a \(60\times60\) square grid of cells, the integers \(1, 2,\cdots,3600\) are filled in such a way that each cell contains exactly one number and each number appears exactly once. For any two adjacent cells (sharing a side), the sum of the two numbers is at least \(S\). Find the maximum possible value of \(S\).
Approach: Use the bipartite structure of the grid (checkerboard coloring). Assign numbers 1 to 1800 in increasing order to black cells (row-major) and numbers 3600 down to 1801 to white cells (row-major). Since every edge connects a black cell to a white cell, each edge sum = (small number) + (large number). The minimum occurs where the largest black number is closest to the smallest white number it is adjacent to. By construction, the critical edge pairs the n/2-th black number (which is n/2 = 30) with the white number N - (n/2 - 1) = 3600 - 29 = 3571, giving minimum sum = 30 + 3541 = 3571. For the upper bound, observe that the n/2 smallest numbers occupy an independent set (same color class). The largest of these (value n/2) must be adjacent to some opposite-color cell whose value is at most N - (n/2 - 1) by pigeonhole on the N/2 opposite-color labels. Thus S <= n/2 + (N - n/2 + 1) = N - (n/2 - 1) = 3571. The pattern S = N - (n/2 - 1) was confirmed computationally for 4x4 (S=15), 6x6 (S=34), 8x8 (S=61), and 60x60 (S=3571).
