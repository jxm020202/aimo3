# Ideas & Strategy Notes

Our own analysis and improvement plans. **Not** Kaggle discussion summaries (those go in `memory/discussions/`).

## File Purposes

- **`strategies.md`** — Future scope. Catalog of all techniques we could use: proven methods, unexploited opportunities, what's failed, research links, priority queue. Read this when planning what to work on next.
- **Individual files** (e.g. `parallelism-and-early-stop.md`) — Deep dives on specific features we're actively planning or building. Each one is a concrete next step with analysis, data, and implementation proposal. Create a new file when a feature needs its own research/design doc.
